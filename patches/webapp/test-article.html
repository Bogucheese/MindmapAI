Intro to AI Agents and Agent Use Cases

This lesson explains what AI agents are and their types, which tasks suit them, and the core pieces for designing an agentic solution.

Defining AI Agents and Types

AI agents are systems that let LLMs act in an environment: the agent has an environment, sensors, and actuators, plus tools and memory.

  • Agent types range from simple reflex agents to Multi-Agent Systems (MAS)
  • Each type fits a different level of autonomy

When to Use AI Agents

Agents shine for open-ended problems, multi-step tool-using processes, and systems that improve over time.

Basics of Agentic Solutions

Agent Development uses Microsoft Foundry Agent Service with models from OpenAI, Mistral, Meta and OpenAPI 3.0 tools.

Agentic Patterns are reusable prompting and orchestration strategies; Agentic Frameworks focus on the Microsoft Agent Framework.
